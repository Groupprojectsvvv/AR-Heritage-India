# Features

- Landing page with navigation, collection cards and responsive layout.
- Individual page for each monument: location, historical background, construction period, architecture, important features, significance, facts and timeline.
- Three-image gallery records per site, sourced from Wikimedia Commons URL endpoints; browser alt text and graceful hidden-image behavior are provided.
- Interactive local GLB viewer via Google `<model-viewer>` with rotation, zoom, camera reset, loading/error feedback and AR modes.
- Speech synthesis narration with play, pause and stop controls.
- Five multiple-choice questions per site with answer checking, immediate feedback, final score and restart.
- Flask JSON endpoints for health, site records and quiz data.
