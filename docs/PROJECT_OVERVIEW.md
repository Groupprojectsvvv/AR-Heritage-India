# Project overview

AR Heritage India is a lightweight Flask-backed educational web application designed to make five Indian heritage monuments approachable through a mix of historical context, architecture, 3D inspection and interactive learning.

## Objectives

- Present monument-specific history in student-friendly language.
- Make supplied 3D models inspectable from desktop and mobile browsers.
- Introduce AR where hardware and browser support permit.
- Reinforce learning through timelines, spoken narration and short quizzes.
- Keep the source code understandable and easy to run on Windows.

The five sites are Sanchi Stupa, Taj Mahal, Konark Sun Temple, Hampi Stone Chariot and Qutub Minar.
