## Photography

Gallery URLs now point to existing, monument-specific Wikimedia Commons file pages. Images are still loaded from Wikimedia at runtime, so the project needs internet access for photographs. Captions link to each source page, where the current author and license details are recorded. Verify each Commons page before reusing a photograph outside this application. Images can change or become unavailable.
